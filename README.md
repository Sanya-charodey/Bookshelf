# Bookshelf

> Учебный проект на Vue 3 и TypeScript. Основной фокус — архитектура компонентов,
> управление состоянием через Pinia и интеграция с внешним API.

> При разработке особое внимание уделялось:
> - разделению бизнес-логики и UI;
> - организации состояния через Pinia-сторы;
> - кешированию API-запросов для сокращения нагрузки;
> - переиспользуемым компонентам и composables.

Приложение для поиска и хранения книг. Каталог с фильтрацией по жанрам, детальные страницы книг и личная полка — всё на данных [Open Library API](https://openlibrary.org/).

## Возможности

- **Каталог книг** — подборка по умолчанию и фильтрация по 30+ жанрам (фэнтези, детектив, научная фантастика и др.).
- **Поиск книг** — поиск по названию, автору и другим полям с пагинацией (по 10 книг на страницу).
- **Детальная страница книги** — обложка, авторы, описание, рейтинг, количество страниц, дата публикации, категории.
- **Личная полка** — добавление и удаление книг, данные сохраняются в `localStorage`.
- **Статусы книг** — «запланировано» / «читаю» / «прочитано», сохраняются в `localStorage`.
- **Кеширование** — поисковые запросы, детали книг и описания кешируются, чтобы снизить нагрузку на API и ускорить повторные просмотры.

## Технологический стек

- [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- [TypeScript](https://www.typescriptlang.org/)

- [Vue Router](https://router.vuejs.org/) — маршрутизация
- [Axios](https://axios-http.com/) — HTTP-запросы

## Требования

- Node.js `^20.19.0 || >=22.12.0`
- [pnpm](https://pnpm.io/) `11.5.0`

## Установка и запуск

```sh
pnpm install      # установка зависимостей
pnpm dev          # запуск dev-сервера с hot-reload
```

## Сборка

```sh
pnpm build        # проверка типов + продакшен-сборка
pnpm preview      # предпросмотр продакшен-сборки
```

## Прочие скрипты

```sh
pnpm type-check   # проверка типов через vue-tsc
pnpm format       # форматирование src/ через Prettier
```

## Структура проекта

```
src/
├── api/            # клиент Open Library, кеширование запросов
├── assets/         # глобальные стили
├── components/     # переиспользуемые компоненты (book, layout, pagination, icons)
├── composables/    # переиспользуемая логика (useBookInfo)
├── router/         # конфигурация маршрутов и guard'ы
├── stores/         # Pinia-сторы (auth, books, shelf, genres, status)
├── types/          # TypeScript-типы и интерфейсы
└── views/          # страницы (Home, Book, Shelf)
```

## Конфигурация

Приложение использует публичное [Open Library API](https://openlibrary.org/). Базовые URL захардкожены в `src/api/openLibrary.ts`:

- `https://openlibrary.org` — поиск и данные о книгах
- `https://covers.openlibrary.org` — обложки книг

`.env`-файлы не используются.
